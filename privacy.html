プライバシーポリシー

「投稿ツール」（以下、本ツール）は、運営者自身が管理するYouTubeチャンネルへ動画を投稿するための個人用ツールです。

取得するGoogleユーザーデータ

  • YouTubeへの動画アップロードの権限（youtube.upload）
  • 投稿先チャンネルの確認のための、チャンネル情報の読み取り権限（youtube.readonly）

利用目的

上記の権限は、運営者の動画をYouTubeに投稿すること、および投稿先のチャンネルが正しいかを確認することにのみ使います。

保存・共有

認可の情報（トークン）は運営者のコンピュータ内にのみ保存します。第三者への提供、販売、広告への利用は行いません。

本ツールによるGoogle APIから取得した情報の利用は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

削除

Googleアカウントの「サードパーティのアクセス」設定から、いつでも権限を取り消せます。
